# Portfolio - Kévin Jovené

Portfolio personnel présentant mes projets, compétences et expériences en tant que développeur Full Stack.

## Technologies utilisées

- **React** avec TypeScript
- **TanStack Router** pour la navigation
- **Vite** comme bundler
- **CSS moderne** avec animations et responsive design

## ✨ Fonctionnalités

- **Design responsive** avec menu hamburger mobile
- **Interface moderne** avec dégradés et animations fluides
- **Sections organisées** : Projets, Compétences, Expériences, Formations
- **Liens sociaux** : GitHub et LinkedIn
- **Section contact** intégrée

## Installation

```bash
# Installation des dépendances
npm install

# Lancement en développement
npm run dev

# Build pour production
npm run build
```
